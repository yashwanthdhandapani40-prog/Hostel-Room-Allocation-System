 Hostel Room Allocation System in Java

 Overview
The Hostel Room Allocation System is a Java-based application designed to simplify the process of allocating hostel rooms to students. It allows users to enter student details, view room information, check room availability, and allocate rooms based on available space. The system automatically updates the room status after allocation and displays the allocation details. If no rooms are available, it displays a "Room Full" message. This project helps reduce manual work, saves time, and improves the efficiency of hostel room management.# 🎯 Objectives
- To manage student details efficiently.
- To check hostel room availability.
- To allocate rooms to students easily.
- To update room status after allocation.
